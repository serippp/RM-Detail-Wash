# RM Detail Wash — demonstração estática

Website de demonstração em HTML, CSS e JavaScript, preparado para alojamento estático.

## Estrutura

- `index.html` na raiz
- `styles.css` e `script.js` locais
- `assets/` com as 8 imagens e os 2 vídeos fornecidos
- `_headers` compatível com Cloudflare Pages

## Publicação no Cloudflare Pages

1. Colocar todo o conteúdo desta pasta na raiz de um repositório GitHub.
2. No Cloudflare Pages, ligar o repositório.
3. Escolher **sem framework**.
4. Deixar o comando de build vazio.
5. Definir o diretório de saída como `/`.

O formulário é exclusivamente demonstrativo e não envia nem guarda dados.
